# Nido · palabras que vuelven a ti

Prototipo navegable de una app para practicar el lenguaje después de una afasia, pensado para tablet. Es un regalo para la app de la Asociación Ayuda Afasia.

Ábrelo en: https://marcefonseca-sys.github.io/nido

- Cuatro bloques (Nombrar, Relacionar, Hacer frases, Atención y más) con tres niveles.
- Lino, el petirrojo, acompaña; cada palabra que vuelve es un hilo del nido.
- La voz de Lino lee todo; el micrófono reconoce la palabra si el navegador lo permite.
- Los deseos, las fotos y el progreso se guardan solo en el dispositivo.
